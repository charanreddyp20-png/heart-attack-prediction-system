# ❤️ Heart Attack Prediction System

## 📌 Project Overview
The Heart Attack Prediction System is a Machine Learning project that predicts the likelihood of a heart attack based on patient health information. It provides predictions using a trained machine learning model and presents the results through a user-friendly interface.

## 🚀 Features
- Predicts the risk of heart attack.
- User-friendly graphical interface.
- Uses a trained Machine Learning model.
- Displays prediction results instantly.
- Uses a heart disease dataset for prediction.

## 🛠️ Technologies Used
- Python
- Machine Learning
- Pandas
- NumPy
- Scikit-learn
- Tkinter (or update this if you used another GUI framework)
- MySQL
- Matplotlib

## ▶️ How to Run
1. Clone the repository:
```bash
git clone https://github.com/charanreddyp20-png/heart-attack-prediction-system.git
```

2. Open the project folder:
```bash
cd heart-attack-prediction-system
```

3. Install the required libraries:
```bash
pip install -r requirement.txt
```

4. Run the application:
```bash
python main.py
```

## 📊 Dataset
The project uses the **Heart Disease Dataset (`heart.csv`)** for training and prediction.
